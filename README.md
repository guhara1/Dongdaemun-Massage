# 간다 GO — 동대문 출장마사지 사이트

동대문 출장마사지·홈타이 안내 정적 사이트입니다. `동대문구 > 대표 동 > 역세권 > 테마` 구조로
도어웨이·중복·얇은 콘텐츠 위험을 줄이는 SEO 설계안을 그대로 구현했습니다.

- 상호: 간다 GO
- 전화: 0508-202-4719

## 빌드 방법

```bash
python3 build.py
```

`content/` 아래의 페이지별 본문을 공통 셸(헤더/네비/푸터)과 결합해 정적 HTML을 생성하고,
`sitemap.xml`과 `robots.txt`를 함께 만듭니다. 빌드 로그에 페이지별 본문 글자수와
index/noindex 여부가 출력됩니다.

> **배포 전 필수**: `build.py` 상단의 `BASE_URL`(현재 `https://www.example.com`)을
> 실제 도메인으로 바꾼 뒤 다시 빌드하세요. canonical, og:url, sitemap에 반영됩니다.

## 구조

| 구역 | URL | 페이지 수 |
|---|---|---|
| 메인 (동대문 출장마사지 허브) | `/` | 1 |
| 서비스 안내 | `/service/` | 1 |
| 지역별 안내 (대표 동) | `/dongdaemun-gu/…` | 인덱스 1 + 동 10 |
| 지하철역별 안내 | `/dongdaemun-gu/stations/…` | 인덱스 1 + 역 9 |
| 테마별 안내 | `/themes/…` | 인덱스 1 + 테마 14 |
| 코스/예약/가이드/후기/고객센터 | `/courses/` 등 | 7 |

## SEO 규칙 (빌드 스크립트가 강제)

- 본문(태그 제거 후) **2,000자 미만 페이지는 자동 noindex** 처리되고 sitemap에서 제외됩니다.
- 숫자 행정동(전농1·2동 등)은 대표 동 페이지로 통합 — 개별 URL을 만들지 않습니다.
- 환승역은 노선이 여러 개여도 URL 하나만 사용합니다.
- 지역+역+테마 조합 페이지(예: 청량리역 스웨디시)는 만들지 않습니다.
- 메뉴·카드에는 지역명·역명만 표기하고, 키워드는 각 페이지 본문(H1/Title)에서만 사용합니다.
- 푸터에 지역명·역명을 나열하지 않습니다.
- 후기·고객센터·약관 페이지는 실콘텐츠가 채워지기 전까지 의도적으로 noindex입니다.

## 콘텐츠 수정

페이지 본문은 `content/` 아래 모듈에 페이지별 dict로 들어 있습니다.

- `core.py` — 메인, 서비스 안내, 지역/역/테마 인덱스
- `dongs.py` — 대표 동 10곳
- `stations.py` — 역세권 9곳
- `themes_a.py` / `themes_b.py` — 테마 14종
- `pages.py` — 코스, 예약, 가이드, 후기, 고객센터, 약관

수정 후 `python3 build.py`를 다시 실행하면 글자수 검증과 함께 전체 페이지가 재생성됩니다.
